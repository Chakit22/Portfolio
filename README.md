# Chakit Bhandari Portfolio

A 3D developer portfolio built with React, TypeScript, Vite, Three.js, GSAP, and Vercel.

This site is adapted from the MIT-licensed [`red1-for-hek/portfolio-website`](https://github.com/red1-for-hek/portfolio-website) template and customized with Chakit Bhandari's projects, experience, links, and deployment setup.

## Tech Stack

- React
- TypeScript
- Vite
- Three.js / WebGL
- GSAP
- Vercel Analytics and Speed Insights

## Local Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Environment

The optional `/play` chat API uses Groq:

```bash
GROQ_API_KEY=your_groq_api_key_here
```
